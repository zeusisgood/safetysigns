# Safety Signs

[English](README.en.md)

ISO 7010 の安全標識をモチーフにした、装飾用の警告看板を追加する Minecraft Mod です。
原子炉のまわりに「放射線注意」、配電盤に「感電注意」など、実物らしい看板を立てられます。看板は見た目だけで、ゲーム上の効果はありません。

> **ISO（国際標準化機構）とは無関係の非公式 Mod です。** 図柄は ISO 7010 を参考に、この Mod のために描き起こしたものです。

![図柄の一覧](doc/textures/preview.png)

## 看板

| アイテム | 大きさ | 置き方 |
|---|---|---|
| 壁掛け看板 1×1 | 1 ブロック | 薄い板を、置いた人の方を向けて置く |
| 壁掛け看板 2×2 | 横 2 × 縦 2 ブロック | 置いた所が左下になり、右・上へ広がる。4 マスとも空いていないと置けない |
| ポール付き看板 | 縦 3 ブロック | 床（ブロックの上面）に置く。下 2 段が支柱、最上段が 1×1 の看板 |

- 向きは 4 方向で、置いた人の方を向きます。
- 2×2・ポール付きは、1 マスでも壊れると全体が消え、アイテムは 1 個だけ落ちます。
- 看板の板は図柄の形（三角・円）に切り抜かれます。

## 操作

| 操作 | 結果 |
|---|---|
| 看板アイテムで右クリック | 設置。アイテムの図柄と設定をそのまま引き継ぐ |
| 置いた看板を右クリック（素手、または看板アイテム以外を持って） | 図柄を選ぶ画面を開く |
| 看板アイテムを持ってスニーク + 置いた看板を右クリック | 置いた看板の図柄と設定を、手に持った看板アイテムに写す（種類・大きさは違ってよい） |
| ピックブロック（ホイールクリック） | 図柄入りのアイテムを取る（クリエイティブ） |
| 看板を壊す | 図柄と設定を持ったアイテムが落ちる |
| 看板アイテム 1 個だけをクラフト枠に入れる | 同じアイテムの無地になる |

### 図柄を選ぶ画面

- 上のタブで分類（警告・禁止・指示・安全状態・防火）を切り替え、左の一覧から図柄を選びます。**押したらすぐ看板に反映**されます（決定ボタンはありません）。
- 下の検索欄で、コード（`W003` など）・日本語名・英語名・キーワードから絞り込めます（全分類が対象）。
- 「無地に戻す」で図柄を外します。
- 看板ごとに次の設定を切り替えられます（どれも押したらすぐ反映）。

| 設定 | 内容 | 初期値 |
|---|---|---|
| 切り抜き | ON: 図柄の形の板 / OFF: 四角い板（図柄の外は明るい金属の地） | ON |
| 裏面 | 銀: 無地の金属板 / 図柄: 裏にも同じ図柄（裏から読める向き） | 銀 |
| 夜間に光る | ON: 表の図柄だけを明るさ最大で描く（周りは照らさない） / OFF: 周りの明るさのまま | ON |

## 図柄

| コード | 分類 | 名前 |
|---|---|---|
| W001 | 警告 | 一般警告 |
| W002 | 警告 | 爆発物 |
| W003 | 警告 | 放射性物質・電離放射線 |
| W012 | 警告 | 感電注意 |
| W017 | 警告 | 高温注意 |
| M010 | 指示 | 防護服着用 |
| P004 | 禁止 | 通行禁止 |
| P010 | 禁止 | 触るな |

リソースパックで図柄を足したり、差し替えたりできます（[doc/resourcepack.md](doc/resourcepack.md)）。パックを入れていない人には「?」の図柄で見えます。

## レシピ

すべて不定形（クラフト枠のどこに置いてもよい）です。

| 作るもの | 材料 | 個数 |
|---|---|---|
| 壁掛け看板 1×1 | 看板（木）1 + 鉄インゴット 1 | 1 |
| 壁掛け看板 2×2 | 看板（木）4 + 鉄インゴット 1 | 1 |
| ポール付き看板 | 看板（木）3 + 鉄インゴット 1 | 1 |
| 無地に戻す | 看板アイテム 1 個だけ | 同じアイテムの無地 1 |

- 鉄インゴットの代わりに、鉱石辞書の `ingotIron`・`plateIron`（他 Mod の鉄インゴット・鉄板）も使えます。
- 看板（木）はバニラの看板です。
- できた看板は無地です。設定は初期値（切り抜き ON・裏面 銀・夜間に光る ON）です。
