# Safety Signs

[English](README.en.md)

ISO 7010 などの安全標識・ハザードシンボルをモチーフにした、装飾用の警告看板を追加する Minecraft Mod です。
原子炉のまわりに「放射線注意」、配電盤に「感電注意」など、実物らしい看板を立てられます。看板は見た目だけで、ゲーム上の効果はありません。

> **ISO・国連・各規格の団体とは無関係の非公式 Mod です。** 図柄は ISO 7010・GHS（化学品の分類および表示に関する世界調和システム）・ISO 21482 を参考に、この Mod のために描き起こしたものです。

![図柄の一覧](doc/textures/preview.png)

## ダウンロード

- [GitHub Releases](https://github.com/zeusisgood/safetysigns/releases) から、Minecraft の版とローダーに合った jar（`safetysigns-1.12.2-forge-<版>.jar`・`safetysigns-1.20.1-forge-<版>.jar`・`safetysigns-1.21.1-neoforge-<版>.jar`）を落とし、`mods` フォルダに入れてください。
- **クライアントとサーバーの両方に必要**です。接続できるのは、同じマイナー版同士（例: 1.1.x 同士）です。

## 看板

| アイテム | 大きさ | 置き方 |
|---|---|---|
| 壁掛け看板 1×1 | 1 ブロック | 薄い板を、置いた人の方を向けて置く |
| 壁掛け看板 2×2 | 横 2 × 縦 2 ブロック | 置いた所が左下になり、右・上へ広がる。4 マスとも空いていないと置けない |
| ポール付き看板 | 縦 3 ブロック | 床（ブロックの上面）に置く。下 2 段が支柱、最上段が 1×1 の看板 |

- 向きは 4 方向で、置いた人の方を向きます。
- 2×2・ポール付きは、1 マスでも壊れると全体が消え、アイテムは 1 個だけ落ちます。
- 看板の板は図柄の形（三角・円・ひし形）に切り抜かれます。

## 操作

| 操作 | 結果 |
|---|---|
| 看板アイテムで右クリック | 設置。アイテムの図柄と設定をそのまま引き継ぐ |
| 置いた看板を右クリック（素手、または看板アイテム以外を持って） | 図柄を選ぶ画面を開く |
| 看板アイテムを持ってスニーク + 置いた看板を右クリック | 置いた看板の図柄と設定を、手に持った看板アイテムに写す（種類・大きさは違ってよい） |
| ピックブロック（ホイールクリック） | 図柄入りのアイテムを取る（クリエイティブ） |
| 看板を壊す | 図柄と設定を持ったアイテムが落ちる |
| 看板アイテム 1 個だけをクラフト枠に入れる | 同じアイテムの無地になる |

### 図柄を選ぶ画面

- 上のタブで分類（警告・禁止・指示・安全状態・防火・GHS・その他）を切り替え、左の一覧から図柄を選びます。**押したらすぐ看板に反映**されます（決定ボタンはありません）。
- 下の検索欄で、コード（`W003` など）・日本語名・英語名・キーワードから絞り込めます（全分類が対象）。
- 「無地に戻す」で図柄を外します。
- 一番左の「最近」のタブに、画面で選んだ図柄が新しい順に 18 個まで並びます（自分の PC の `config/safetysigns_recent.json` に残り、ワールド・サーバーをまたいで同じです）。
- 検索欄は右クリックで文字が消えます。右上の「×」か Esc で閉じます。
- 看板ごとに次の設定を、画面の一番下の段で切り替えられます（どれも押したらすぐ反映。マウスを乗せると説明が出ます）。

| 設定（ボタンの名前） | 内容 | 初期値 |
|---|---|---|
| 切り抜き（形） | 標識: 図柄の形の板 / 四角: 四角い板（図柄の外は明るい金属の地） | 標識 |
| 裏面（裏側） | 金属: 無地の金属板 / 図柄: 裏にも同じ図柄（裏から読める向き） | 金属 |
| 夜間に光る（蓄光） | あり: 表の図柄だけを明るさ最大で描く（周りは照らさない） / なし: 周りの明るさのまま | あり |

## レシピ

すべて不定形（クラフト枠のどこに置いてもよい）です。

| 作るもの | 材料 | 個数 |
|---|---|---|
| 壁掛け看板 1×1 | 看板（木）1 + 鉄インゴット 1 | 1 |
| 壁掛け看板 2×2 | 看板（木）4 + 鉄インゴット 1 | 1 |
| ポール付き看板 | 看板（木）3 + 鉄インゴット 1 | 1 |
| 無地に戻す | 看板アイテム 1 個だけ | 同じアイテムの無地 1 |

- 鉄インゴットは、他 Mod の鉄インゴットも使えます（1.12.2 は鉱石辞書の `ingotIron`、1.20.1 はタグ `forge:ingots/iron`、1.21.1 はタグ `c:ingots/iron`）。1.12.2 だけは、鉱石辞書の `plateIron`（鉄板）も使えます。
- 看板（木）はバニラの看板です（1.20.1・1.21.1 はどの木の看板でもよい）。
- できた看板は無地です。設定は初期値（形 標識・裏側 金属・蓄光 あり）です。
