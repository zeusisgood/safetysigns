# 0007. 切り抜きと裏面は看板ごとに NBT に持ち、図柄と一緒に持ち運ぶ

- 日付: 2026-10-12
- 状態: 決定（0.5.0。[SPEC_2026-10-12-3.md](../spec/SPEC_2026-10-12-3.md)）

## 背景

SPEC_2026-10-12-3 で、看板ごとに次の 2 つを図柄選択の GUI で選べるようにする。

- 切り抜き: ON（図柄の形。0.4.0 の見た目）/ OFF（四角い板に下地と図柄）
- 裏面: 銀（灰色の金属板。0.4.0 の見た目）/ 図柄（裏にも表と同じ図柄）

既存のワールドの看板は、見た目を変えたくない。

## 決定

- 図柄 ID・切り抜き・裏面の 3 つを、変えられない値 `common/SignAppearance` にまとめる。TileEntity・アイテム・通信（`MessageSetSign`）・GUI で同じものを持ち運ぶ。
- NBT は図柄 ID（`SignId`）と同じ場所に、`Cutout`（OFF のときだけ `false`）と `BackPattern`（図柄のときだけ `true`）を足す。既定の値はキーを書かない。
  - キーがない既存の看板とアイテムは、切り抜き ON・裏面 銀（0.4.0 の見た目）のまま。
  - 既定の見た目のアイテムは NBT を持たないので、無地のアイテムとスタックできる。
- `MessageSetSign` は、図柄 ID のあとに切り抜きと裏面の真偽値を送る。図柄を選んでもボタンを押しても、3 つ全部を送る。サーバーは今までどおり、ID の形・距離・場所を確かめてから書き込む。
- 設置・コピー（スニーク右クリック）・ドロップ・ピックブロックは、3 つまとめて持ち運ぶ。無地に戻すクラフトは NBT をなくすので、3 つとも既定に戻る。
- 描き方（`SignRenderer`）:
  - 切り抜き OFF は、形を四角にし、表に無地のテクスチャ（下地）を貼ってから図柄を重ねる。
  - 裏面 図柄は、裏の灰色の代わりに図柄（切り抜き OFF なら下地も）を貼る。テクスチャの左右（u）を入れ替えて貼るので、裏から見て読める向きになる（そのまま貼ると、裏からは左右逆に見える）。
  - ディスプレイリストのキーに、切り抜きと裏面を足す。

## 検討した案

- **クライアントの設定（`config/safetysigns.cfg`）で、全部の看板をまとめて切り替える**: 通信が変わらず、パッチで済む。ただし看板ごとには選べず、見る人によって見た目が違う。ユーザーの要望（GUI で看板ごとに選ぶ）に合わない。
- **切り抜き・裏面だけを送る別の通信を足す**: 図柄の通信と分かれて、順番がずれたときに扱いが増える。どちらにしても互換性を破るので、1 つの通信に 3 つを載せた。
- **裏にテクスチャをそのまま貼る（表を透かして見た向き）**: 裏からは図柄が左右逆に見え、両面の標識としては読めない。

## 結果

- 通信内容が変わるので、0.5.0 にし、0.4.x とは接続できない。0.4.x のワールドはそのまま読める。
- 無地は切り抜きの ON/OFF で見た目が変わらないので、`SignAppearance` が常に ON にそろえる（GUI のボタンは ON のまま押せない表示）。「切り抜き OFF → 無地に戻す → 別の図柄」とすると、切り抜きは ON から始まる。
- 切り抜き OFF のアイテムは、キーを 1 つ持つので、既定のアイテムとはスタックしない（図柄違いと同じ扱い）。無地は常に切り抜き ON なので、無地のアイテムが切り抜きのキーを持つことはない（ふつうの無地とスタックできる）。
