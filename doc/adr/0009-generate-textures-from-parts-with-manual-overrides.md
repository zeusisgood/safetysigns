# 0009. 図柄のテクスチャは、部品の組み合わせでスクリプトが描き、手で仕上げた図柄を優先する

- 日付: 2026-10-12
- 状態: 決定（0.6.1。[SPEC_2026-10-12.md](../spec/SPEC_2026-10-12.md) の 3.3）

## 背景

MVP の 8 種から始めて、最終的には ISO 7010 の約 330 種を描く。形（三角・円）と色のきまりは種類ごとに同じで、記号（感嘆符・放射線マーク・稲妻など）は図柄をまたいで使い回せる。
一方で、人物の入る図柄は、図形の組み合わせだけでは不自然になりやすい。テクスチャは 32×32 なので、1 ピクセルの違いで見え方が大きく変わる。

## 決定

- `tools/texgen/` の Python 3 + Pillow のスクリプトで描く。出力の PNG はコミットし、ビルドには Python を持ち込まない。
- 標識の形（警告・禁止・指示）と、記号の部品（`parts.py`）を分ける。図柄は「形 + 部品と位置」の組み合わせで `generate.py` の `SIGNS` に定義する。
- ドット絵として描く。形はピクセルの中心で内外を決め、記号は「#」で書いたドット絵か、ピクセルごとの計算で塗る。アンチエイリアスは使わない。生成した図柄に決めた色と透明以外のピクセルがあれば、スクリプトを止める。
- 手で仕上げた図柄は `tools/texgen/manual/<名前>.png` に置き、生成より優先してそのままコピーする。スクリプトを流し直しても上書きしない。
- 全図柄を 8 倍に拡大し、定義ファイルのコードと英語の名前を添えた一覧画像 `doc/textures/preview.png` を出す。文字は Pillow 内蔵のフォントで描く（手元のフォントで画像が変わらないように）。

## ほかの案

- **全部を手で描く（PNG だけを持つ）**: 形・枠・色のきまりを図柄ごとに守る手間が大きく、330 種で揃わなくなる。
- **ベクター（SVG）で描いて縮小する**: 32×32 に縮めると中間色とにじみが出て、切り抜きの形（アルファ）も曖昧になる。
- **手の仕上げを、生成した PNG への差分（パッチ）で持つ**: 形を直すと差分がずれる。ファイルごと置き換えるほうが分かりやすい。
- **一覧画像の名前を日本語にする**: 日本語のフォントは環境ごとに違い、Pillow に内蔵されていない。英語の名前にした。

## 影響

- 図柄を足す手順は `doc/development.md`。流れの図は `doc/diagrams/texture-generation.md`。
- （注: 1.0.1 で、テクスチャを 64×64 にし、部品を解像度によらない設計の座標の図形で書いて、出力のマス目に直接塗る作りに変えた。本体の図柄は手の仕上げを使わない。[ADR 0011](0011-draw-textures-on-a-resolution-independent-grid.md)）
- `manual/` に置いた図柄は、形のきまりや部品を直してもスクリプトの変更が反映されない。直したら手で合わせるか、ファイルを消して生成に戻す。
