# 0010. 看板は、木の看板と鉄の不定形 JSON レシピで作る

- 日付: 2026-10-12
- 状態: 決定（1.0.0。[SPEC_2026-10-12-5.md](../spec/SPEC_2026-10-12-5.md)）

## 背景

MVP の仕様書の「6. レシピ」は、鉄 3 と染料 2 で 1×1 を 6 枚、1×1 を 4 枚並べて 2×2、1×1 と鉄格子でポール付き、という案だった。
SPEC_2026-10-12-5 で、木の看板と鉄インゴットの不定形のレシピに変えた。鉄は他 Mod の鉄インゴット・鉄板（`ingotIron`・`plateIron`）も受け付ける。

## 決定

- レシピは JSON（`assets/safetysigns/recipes/<アイテム名>.json`、`minecraft:crafting_shapeless`）で書く。Forge が起動時に読む。
- 鉄の材料は、`forge:ore_dict` の `ingotIron` と `plateIron` を JSON の配列で並べた 1 つの材料欄にする（Forge はこれを「どれか 1 つ」の材料として読む）。`plateIron` を入れる Mod がなくても、`ingotIron` だけで動く。
- 木の看板はバニラの看板（`minecraft:sign`）だけ。Forge 14.23.5.2860 は看板を鉱石辞書に登録しておらず、Mod の間で広く使われている看板の鉱石辞書名も見当たらないため。
- 完成品は NBT なし（無地・設定は初期値）。
- 無地に戻すレシピ（`RecipeClearSign`）はコードのまま。材料に鉄が入らないので、作るレシピとはぶつからない。

## ほかの案

- **コードでレシピを登録する（`ShapelessOreRecipe`）**: 同じことができるが、JSON のほうが材料と結果を見たまま書け、コードを読まずにレシピを確かめられる。
- **看板の鉱石辞書名を自分で決めて登録する（`sign` など）**: 他 Mod がその名前を使わなければ意味がなく、ほかの Mod のレシピに思わぬ形で効くおそれがある。

## 影響

- バニラ 1.12.2 には看板を材料にするレシピがなく、鉄インゴット 1 個を使う不定形のレシピは火打石と打ち金（鉄 + 火打石）だけなので、ぶつからない。他 Mod とのぶつかりは、入れている Mod の組み合わせで JEI を見て確かめる。
- 看板の数で作るものが決まる（1・3・4 枚）。2 枚 + 鉄は何もできない。
