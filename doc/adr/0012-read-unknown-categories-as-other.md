# 0012. 定義ファイルの知らない category は OTHER として読む

- 日付: 2026-10-12
- 状態: 決定（1.0.2。[SPEC_2026-10-12-7.md](../spec/SPEC_2026-10-12-7.md)）

## 背景

GHS 絵表示と ISO 21482 の標識を足すにあたり、ISO 7010 の 5 分類（W P M E F）の外に、分類 `GHS` と `OTHER` を足した。
今後も国連の危険物輸送ラベル（「輸送」タブ）などで分類が増える見込みがある。
今までは、`category` が知らない値の項目は飛ばしていたので、新しい版の Mod 向けに作ったリソースパックを古い版で読むと、その図柄が一覧から消え、置いた看板が「?」になっていた。

## 決定

- 分類は `SignCategory` の enum のまま増やす（`GHS`・`OTHER`）。並び順が GUI のタブの順。
- 定義ファイルの `category` が知らない値なら、**項目を捨てずに `OTHER` として読み**、ログに警告を出す。
- `category` がない・空の項目は今までどおり飛ばす（書き忘れを分類の追加と区別するため）。

## ほかの案

- **知らない値の項目を今までどおり飛ばす**: 分類を足すたびに、古い版で新しいパックの図柄が消える。
- **定義ファイルで自由な分類を作れるようにする（タブを動的に増やす）**: パックごとにタブが増えて GUI の幅に収まらなくなる。タブの色・名前の翻訳も定義ファイルに持たせる必要があり、重い。

## 影響

- 1.0.1 以前で `category` を打ち間違えていた項目は、今まで飛ばされていたが、これからは「その他」のタブに出る（ログの警告で気づける）。
- 分類を足すときは、enum と言語ファイル（`gui.safetysigns.category.<小文字の名前>`）とタブの文字を足す。
