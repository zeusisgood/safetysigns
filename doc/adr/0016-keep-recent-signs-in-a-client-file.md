# 0016. 最近使った図柄をクライアントのファイルに残す

- 日付: 2026-10-25
- 状態: 決定（[SPEC_2026-10-25-3.md](../spec/SPEC_2026-10-25-3.md)）

## 背景

図柄を選ぶ画面に「最近」のタブを足す。履歴をどこに残すかで、通信・保存データ・版の上げ方が変わる。

## 決定

- 履歴はクライアントだけが持ち、設定のフォルダの `safetysigns_recent.json` に残す（`{"version": 1, "recent": [...]}`）。ワールド・サーバーをまたいで同じ履歴。サーバーは知らない。
- 最大 18 個。一覧にない ID も数えて残す（パックを戻すとまた出る）。計算と JSON の形は `common/RecentSigns`、ファイルの場所と読み書きは各版の `client/RecentSignsFile`。
- 読むのは起動してから初めて使うときに 1 回。書くのは記録して変わるたび。`.tmp` に書いてから置き換える。読めない・書けないときは警告を出して続ける。

## ほかの案

- **サーバーのプレイヤーデータ**: ワールドごとに別の履歴になるが、通信を足すのでマイナーを上げることになり、古いクライアントとつながらなくなる。
- **`@Config`（`safetysigns.cfg`）**: 決まりどおりの設定ファイルだが、使った記録は設定ではない。設定の画面にも出てしまう。
- **1 行に 1 つのテキスト**: 一番簡単だが、版の印を持てない。

## 影響

- 通信・看板の保存データは変わらないので、パッチで出せる。
- ランチャーのインスタンスごとに別の履歴になる（`config/` が分かれるため）。
- お気に入りを足すときは、別のファイル `safetysigns_favorites.json` にする。
