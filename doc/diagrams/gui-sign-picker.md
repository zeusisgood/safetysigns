# 図柄選択の GUI の画面遷移

`client/gui/GuiSignPicker` の状態の移り変わり（0.2.0）。仕組みを変えたら、同じ PR でこの図を直す。

- 開いたとき: 今の図柄のカテゴリのタブ。無地・一覧にない図柄なら、図柄のある最初のタブ。
- 検索欄に文字があるあいだは、タブの選択を外して全カテゴリ横断で絞り込む。検索欄を空にすると、タブの表示に戻る。
- 図柄のクリックと「無地に戻す」は、そのたびにサーバーへ送る（決定ボタンはない）。
- 看板が壊れた・8 ブロックより離れたら、毎 tick の確認で閉じる。

```mermaid
stateDiagram-v2
    [*] --> Tab: 看板を右クリック（看板アイテム以外）
    Tab: タブ表示（1 カテゴリ）
    Search: 検索表示（全カテゴリ横断）
    Tab --> Tab: 別のタブ（図柄のあるタブだけ）
    Tab --> Search: 検索欄に入力
    Search --> Search: 入力のたびに絞り込む
    Search --> Tab: 検索欄を空にする / タブを押す
    Tab --> Send: 図柄をクリック / 無地に戻す
    Search --> Send: 図柄をクリック / 無地に戻す
    Send: サーバーへ MessageSetSign
    Send --> Tab: 検索欄が空
    Send --> Search: 検索中
    Tab --> [*]: Esc / 看板が壊れた・離れた
    Search --> [*]: Esc / 看板が壊れた・離れた
```
