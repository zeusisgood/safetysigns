# リソースパックで図柄を追加する

Safety Signs の図柄は、リソースパックで追加・上書きできる。図柄の一覧はクライアントだけが読むので、
サーバーにパックを入れる必要はない（ただし、パックを入れていない人には「?」の図柄で見える）。

## 置き場所

```
<パック>/
├─ pack.mcmeta
└─ assets/<namespace>/
   ├─ safetysigns/signs.json      ← 定義ファイル
   └─ textures/signs/<名前>.png   ← 図柄のテクスチャ（32×32）
```

- `<namespace>` は自分のパックの名前空間（小文字・数字・`_` `.` `-`）。図柄 ID は `<namespace>:<名前>` になる。
- **定義ファイルの ID の名前空間は、ファイルが置かれている名前空間と同じでなければならない**（違う項目は無視される）。
- 本体の図柄（`safetysigns:w003` など）を差し替えるときは、`assets/safetysigns/safetysigns/signs.json` に同じ ID を書く。
  リソースパックの一覧で上にあるパックの定義が、項目ごと丸ごと勝つ。

## 定義ファイルの形

```json
{
  "signs": [
    {
      "id": "mypack:w100",
      "category": "W",
      "code": "W100",
      "texture": "mypack:signs/w100",
      "names": { "en_us": "My warning", "ja_jp": "独自の警告" },
      "keywords": ["custom", "独自"]
    }
  ]
}
```

| 項目 | 必須 | 内容 |
|---|---|---|
| `id` | 必須 | `<namespace>:<名前>`。64 文字まで。小文字・数字・`_` `.` `-`（名前は `/` も）。**一度配ったら変えない**（置いた看板の見た目が変わる） |
| `category` | 必須 | `W` 警告 / `P` 禁止 / `M` 指示 / `E` 安全状態 / `F` 防火。GUI のタブ |
| `code` | 任意 | 表示用のコード。省略したら ID の名前を大文字にしたもの |
| `texture` | 任意 | ブロックのテクスチャの名前（`textures/` と `.png` を付けない）。省略したら `<namespace>:signs/<名前>` |
| `names` | 任意 | 言語コードごとの名前。検索はすべての言語の名前が対象。表示中の言語がなければ `en_us`、それもなければコード |
| `keywords` | 任意 | 検索用の語 |

- 形のおかしい項目は、ログ（`latest.log`）に `[safetysigns]` の警告を出して飛ばす。ほかの項目は使われる。
- F3+T でリソースを読み直すと、定義ファイルも読み直す。

## テクスチャ

- 32×32 の PNG。標識の形と枠（黄色の地・黒い枠など）も含めて描く。
- 透明な部分には、看板の無地の板が見える。
