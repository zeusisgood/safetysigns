# リソースパックで図柄を追加する

Safety Signs の図柄は、リソースパックで追加・上書きできる。図柄の一覧はクライアントだけが読むので、
サーバーにパックを入れる必要はない（ただし、パックを入れていない人には「?」の図柄で見える）。

## 置き場所

```
<パック>/
├─ pack.mcmeta
└─ assets/<namespace>/
   ├─ safetysigns/signs.json      ← 定義ファイル
   └─ textures/signs/<名前>.png   ← 図柄のテクスチャ（2 の累乗の正方形。本体は 64×64、一部 128×128）
```

- `<namespace>` は自分のパックの名前空間（小文字・数字・`_` `.` `-`）。図柄 ID は `<namespace>:<名前>` になる。
- **定義ファイルの ID の名前空間は、ファイルが置かれている名前空間と同じでなければならない**（違う項目は無視される）。
- 本体の図柄（`safetysigns:w003` など）を差し替えるときは、`assets/safetysigns/safetysigns/signs.json` に同じ ID を書く。
  リソースパックの一覧で上にあるパックの定義が、項目ごと丸ごと勝つ。

## 定義ファイルの形

```json
{
  "signs": [
    {
      "id": "mypack:w100",
      "category": "W",
      "code": "W100",
      "texture": "mypack:signs/w100",
      "names": { "en_us": "My warning", "ja_jp": "独自の警告" },
      "keywords": ["custom", "独自"]
    }
  ]
}
```

| 項目 | 必須 | 内容 |
|---|---|---|
| `id` | 必須 | `<namespace>:<名前>`。64 文字まで。小文字・数字・`_` `.` `-`（名前は `/` も）。**一度配ったら変えない**（置いた看板の見た目が変わる） |
| `category` | 必須 | `W` 警告 / `P` 禁止 / `M` 指示 / `E` 安全状態 / `F` 防火 / `GHS` GHS 絵表示 / `OTHER` その他。GUI のタブ（大文字小文字は区別しない）。知らない値は警告を出して `OTHER` として扱う |
| `code` | 任意 | 表示用のコード。省略したら ID の名前を大文字にしたもの |
| `texture` | 任意 | ブロックのテクスチャの名前（`textures/` と `.png` を付けない）。省略したら `<namespace>:signs/<名前>` |
| `names` | 任意 | 言語コードごとの名前。検索はすべての言語の名前が対象。表示中の言語がなければ `en_us`、それもなければコード |
| `keywords` | 任意 | 検索用の語 |

- 形のおかしい項目は、ログ（`latest.log`）に `[safetysigns]` の警告を出して飛ばす。ほかの項目は使われる。
- F3+T でリソースを読み直すと、定義ファイルも読み直す。

## テクスチャ

- PNG。**2 の累乗の正方形なら解像度を問わない**（16×16・32×32・64×64・128×128 …）。本体の図柄は 64×64（64 で潰れる一部の図柄だけ 128×128）。
  - 本体の図柄と解像度が違っても、看板・アイテム・GUI では同じ大きさに描く（細かいテクスチャほど細かく見える）。板の形もテクスチャの幅・高さに対する割合で作るので、ずれない。
  - 2 の累乗の正方形でないと、ログに `should be a power-of-two square` の警告を出す（描画はするが、板が縦横に引き伸ばされたり、ブロックのテクスチャ全体のミップマップが下がって遠くがちらついたりする）。
  - 16 より小さいテクスチャ（8×8 など）は、ブロックのテクスチャ全体のミップマップを下げる（バニラの動き）。16 以上にする。大きいテクスチャ（256 以上）はテクスチャの地図の場所を多く使うので、たくさん足すときは 64〜128 にとどめる。
- 標識の形と枠（黄色の地・黒い枠、GHS の白地と赤いひし形の枠など）も含めて描く。
- 標識の形の外側は透明にする。看板の板は、テクスチャの透明でない所の形に切り抜かれる（透明な所は板がなく、向こう側が見える）。裏面は同じ形の灰色の板になる。
- アルファが 26 以上（約 10%）のピクセルを板にする。半透明のピクセルも、板になる所は不透明に描かれる。
- アニメーションするテクスチャ（`.mcmeta`）では、板の形は最初のコマで決まる。

## 夜間に光る設定

- 看板ごとに「夜間に光る」（初期値 ON）を持つ。ON の看板は、**表の図柄のテクスチャだけ**を明るさ最大で描く（周りは照らさない）。裏面・縁・切り抜き OFF の下地・ポールは周りの明るさのまま。
- 光るかどうかは看板の設定で、定義ファイルやテクスチャには書かない（書く項目はない）。足した図柄も、ON の看板では同じように光る。
- テクスチャの色は、明るさ最大のときにそのままの色で見える。暗い所でも浮きすぎないように、真っ白や蛍光色の広い面は避け、本体の図柄と同じくらいの色（[development.md](development.md) の色の表）にすると揃う。
- 透明な所（切り抜きで板がない所）は光らない。

## 例: 図柄を 1 つ足すパック

```
mypack/
├─ pack.mcmeta                              ← {"pack": {"pack_format": 3, "description": "My signs"}}
└─ assets/mypack/
   ├─ safetysigns/signs.json                ← 上の「定義ファイルの形」の例
   └─ textures/signs/w100.png               ← 64×64（2 の累乗の正方形）、外側は透明
```

- 1.12.2 のリソースパックの `pack_format` は `3`。
- パックを有効にすると、図柄を選ぶ画面に `W100` が出る。図柄 ID は `mypack:w100` になる。
- 本体の図柄と同じ描き方（ドット絵・色・形）にしたいときは、[development.md](development.md) のきまりとスクリプト（人物・手・矢印などの部品。一覧は [textures/parts.png](textures/parts.png)）を使える。
