# Safety Signs 仕様書（2026-10-12・その 2）: 看板の板を図柄の形に切り抜く・ポール付きを縦 3 ブロックに

[MVP の仕様書](SPEC_2026-10-12.md)との差分。看板（壁掛け 1×1・2×2・ポール付き）の見た目を、実物の標識に近づける。
ここに書いていないことは、MVP の仕様書と現行の実装のまま。

同じ日に 2 つ目の仕様書なので、ファイル名の日付のあとに `-2` を付けた。

## 1. 共通（壁掛け 1×1・2×2・ポール付き）

| 項目 | MVP | この版 |
|---|---|---|
| 板の形 | 四角い板に図柄を重ねる | **図柄の形（三角・円・四角）に切り抜く**。図柄のテクスチャの透明な所は描かない（cutout） |
| 裏面 | 無地の金属板 | 表と同じ形の**灰色の金属板**（`#8C9196`） |
| 当たり判定 | 板（四角） | 変えない。切り抜いた形ではなく、**板の外形の四角**でよい |

- 無地（図柄なし）の看板は、無地のテクスチャ（四角）の形の板。
- 一覧にない ID の「?」は、「?」のテクスチャの形の板。
- 2×2 は、図柄を 2×2 に引き伸ばした形に切り抜く。

（注: 実装では、板はブロックモデルではなく TileEntity の描画が、テクスチャの透明でない所から作った形で描く。板の厚さは 1 ピクセル。アイテムのアイコンと GUI のプレビューも、無地の板に重ねず図柄のテクスチャだけを出す。詳しくは ADR 0006）

## 2. ポール付き看板

| 項目 | MVP | この版 |
|---|---|---|
| 高さ | 縦 2 ブロック（下段が支柱、上段に看板） | **縦 3 ブロック**（下 2 段が支柱、最上段に看板） |
| 設置 | 2 マスとも置き換え可能でなければ失敗 | **3 マスとも**置き換え可能でなければ失敗（アイテムは減らない） |
| ポール | 板の裏まで伸びる | 看板の裏側まで通し、**上端の少し下で止める**。看板はポールの手前に付く |
| 固定金具 | なし | 看板とポールの間に、**小さな固定金具を 2 か所**（`#8C9196`） |
| ポールの太さ・色 | 4 ピクセル角、`#A7ADB2` 基調 | 4 ピクセル角のまま、**`#DDE0E2` 基調** |
| 当たり判定 | 支柱は細く、板は薄い | **支柱の段は細い柱、看板の段は板の外形の四角** |

- 3 マスのどれが壊れても全体が消え、アイテムは 1 個だけ落ちる（MVP 2.1 のまま）。どのマスを右クリックしても同じ看板として扱う。

（注: 実装では、代表のマスは置いた所（最下段の支柱）のまま。ポールは最上段の y = 13/16 で止まり、固定金具は支柱を囲む 6 ピクセル角・高さ 2 ピクセルの輪を 2 つ。板は支柱から金具の分（1 ピクセル）離れた手前に付く。詳しくは ADR 0005）

## 3. テクスチャ

- 図柄のテクスチャは、**標識の形の外側を透明にする**前提に変える（透明な所は板が切り抜かれ、向こう側が見える）。リソースパックで足す図柄も同じ（`doc/resourcepack.md`）。
- 仮のテクスチャも、外側を透明にしたものにする。
- 裏面・固定金具（`sign_back`）を `#8C9196`、支柱（`sign_pole`）を `#DDE0E2` 基調にする。どちらも `tools/texgen/` で作る。
- 一覧画像（`doc/textures/preview.png`）は、無地の板に重ねず、暗い背景に図柄だけを並べる（切り抜いた形が分かるように）。

（注: 実装では、MVP の仮のテクスチャ 8 種と「?」は、もともと外側が透明だったので PNG は変わらない）

## 4. 互換性

- ポール付き看板は 0.4.0（まだ公開していない）で足したものなので、高さを変えても既存のワールドへの影響はない。版は 0.4.0 のまま。
- 壁掛け看板 1×1・2×2 は、ブロックの状態とメタデータ・NBT を変えない（見た目だけ）。
