# Safety Signs 仕様書（2026-10-12・その 3）: 切り抜きと裏面の図柄を看板ごとに選ぶ

[その 2 の仕様書](SPEC_2026-10-12-2.md)との差分。その 2 で看板の板を図柄の形に切り抜き、裏を灰色の金属板にした。これを看板ごとに選べるようにする。

- **切り抜き**: ON（図柄の形）/ OFF（四角い板）
- **裏面**: 銀（無地の金属）/ 図柄（裏にも表と同じ図柄。両面の看板）
ここに書いていないことは、それまでの仕様書と現行の実装のまま。

同じ日に 3 つ目の仕様書なので、ファイル名の日付のあとに `-3` を付けた。

## 1. 切り抜きの ON/OFF

| 項目 | 内容 |
|---|---|
| 持つ場所 | **看板 1 枚ごと**。看板（TileEntity）とアイテムの NBT に持つ。複数ブロックの看板は、図柄と同じく代表のマスが持つ |
| 既定 | **ON**（その 2 の見た目）。NBT にキーがなければ ON。既存のワールドの看板とアイテムは見た目が変わらない |
| 選び方 | 図柄選択の GUI で切り替える（3 章） |
| 対象 | 壁掛け 1×1・2×2・ポール付きのすべて |

- 無地の看板は、もともと四角なので ON/OFF で見た目は変わらない。値は保持する（あとで図柄を選んだときに使う）。
- 一覧にない ID（「?」）の看板も、ON/OFF の値はそのまま保持する。

## 2. OFF のときの見た目

- 板は、看板の外形のまま四角く描く（1×1 は正方形、2×2 は 2×2 ブロックの正方形、ポール付きは最上段の 1×1）。
- 表は、**下地に無地のテクスチャ**（明るい金属 `#E4E6E8`、周りに `#A7ADB2` の細い枠）を貼り、その上に図柄を重ねる。図柄の透明な所から下地が見える。
- 裏と縁は、ON と同じ灰色（`#8C9196`）。形が四角になるだけ。
- 当たり判定は ON/OFF とも変えない（板の外形の四角）。

| 用途 | 色 |
|---|---|
| OFF の下地（無地のテクスチャの中） | `#E4E6E8` |
| OFF の下地の枠 | `#A7ADB2` |
| 裏・縁 | `#8C9196`（その 2 のまま） |

## 2.5 裏面（銀 / 図柄）

| 項目 | 内容 |
|---|---|
| 持つ場所 | 切り抜きと同じく**看板 1 枚ごと**。看板（TileEntity）とアイテムの NBT に持つ |
| 既定 | **銀**（その 2 の見た目）。NBT にキーがなければ銀 |
| 銀 | 裏は無地の灰色の金属板（`#8C9196`、その 2 のまま） |
| 図柄 | 裏にも表と同じ図柄を貼る。**裏から見て正しく読める向き**（両面に印刷した標識と同じ。表を透かして見たような左右逆の向きにはしない） |

- 縁（厚さの面）は、どちらでも灰色（`#8C9196`）。
- 切り抜きとの組み合わせ:
  - 切り抜き ON・裏面 図柄: 裏も同じ形で、図柄を貼る（透明な所は板がない）。
  - 切り抜き OFF・裏面 図柄: 裏も四角で、下地（`#E4E6E8`）の上に図柄を重ねる（表と同じ）。
  - 裏面 銀: 切り抜きの ON/OFF に合わせた形の灰色の板。
- 無地の看板は、裏面 図柄にすると裏も無地のテクスチャ（明るい金属 `#E4E6E8`）になる。
- ポール付き看板では、裏面 図柄にしても、支柱と固定金具は今のまま（板の裏の、支柱が重なる所は支柱で隠れる）。
- アイテムのアイコンは表だけを出すので、裏面の設定はアイコンに出さない。ツールチップに、裏面 図柄のときだけ「両面」を 1 行足す。
- 設置・コピー・ドロップ・ピックブロックで持ち運ぶこと、無地に戻すクラフトで既定（銀）に戻ることは、切り抜きと同じ（4 章）。

## 3. GUI

- 右下の「無地に戻す」の近くに、2 つの切り替えボタンを置く。押すたびに切り替わる。
  - **「切り抜き: ON / OFF」**
  - **「裏面: 銀 / 図柄」**
- 図柄と同じく**押したら即反映**（決定ボタンなし）。押すたびにサーバーへ送る。
- 右のプレビューも、切り抜きのあり・なしをすぐ反映する（プレビューは表だけ。裏面はボタンの表示で分かる）。
- 無地の看板のあいだは、「切り抜き」のボタンを押せない表示にする（形が変わらないため）。「裏面」のボタンは無地でも押せる。
- ボタンの文字は `en_us.lang` と `ja_jp.lang` の両方に足す。

## 4. アイテム・操作

- アイテムのアイコンにも反映する。OFF なら下地の上に図柄を重ねた四角いアイコン、ON なら今のまま（図柄の形）。
- ツールチップに、OFF のときだけ「切り抜きなし」を 1 行足す（ON は今のまま何も足さない）。
- 設置するとき、アイテムの ON/OFF を看板に引き継ぐ（図柄と同じ）。
- 次の操作でも、図柄と一緒に ON/OFF を持ち運ぶ。
  - スニーク右クリックでのコピー（看板 → 手のアイテム）
  - 壊したときのドロップ
  - ピックブロック
- 看板アイテム 1 個だけのクラフト（無地に戻す）では、切り抜きと裏面の設定も消えて既定（切り抜き ON・裏面 銀）に戻る（NBT なしになる）。

## 5. サーバー

- クライアントから届く切り抜き・裏面の値も、図柄と同じく、看板が届く距離にあるか・いじってよい場所かを確かめてから書き込む。
- サーバーは図柄の形を知らなくてよい（切り抜き・裏面の真偽値を保存・同期するだけ）。

- サーバーへ送る中身（通信内容）に切り抜きと裏面の値が増えるため、互換性を破る。**0.5.0** にし、`acceptableRemoteVersions` を `[0.5,0.6)` にする。`CHANGELOG.md` に 0.4.x とは接続できないことを書く。
