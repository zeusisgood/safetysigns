## 1. レシピ

すべて**不定形**（クラフト枠のどこに置いてもよい）。

| 作るもの | 材料 | 個数 |
|---|---|---|
| 壁掛け看板 1×1 | 木の看板 1 + 鉄インゴット 1 | 1 |
| 壁掛け看板 2×2 | 木の看板 4 + 鉄インゴット 1 | 1 |
| ポール付き看板 | 木の看板 3 + 鉄インゴット 1 | 1 |
| 無地に戻す | 看板アイテム 1 個だけ | 同じアイテムの無地 1 |

- 鉄インゴットは、鉱石辞書の `ingotIron` と `plateIron`（鉄板。IC2 など）のどちらも受け付ける。
- 木の看板は、他 Mod の看板を受け付ける共通の鉱石辞書名があれば使い、なければバニラの看板（`minecraft:sign`）だけ。
- 完成品は無地（NBT なし）。切り抜き・裏面・夜間に光るは初期値（切り抜き ON・裏面 銀・光る ON）。
- バニラや他の Mod のレシピとぶつからないこと（同じ材料の組み合わせで別の物ができないこと）を確かめる。
- MVP の仕様書にあった黄・黒の染料、1×1 を 4 枚並べる 2×2、鉄格子を使うポール付きは作らない。

（注: 実装では、Forge 14.23.5.2860 は看板を鉱石辞書に登録しておらず、Mod の間で広く使われている看板の鉱石辞書名も見当たらないので、木の看板はバニラの看板だけにした。レシピは JSON（`assets/safetysigns/recipes/`）で、鉄の材料は `ingotIron` と `plateIron` の鉱石辞書の材料を並べた 1 つの材料欄（どちらか 1 つ）。バニラ 1.12.2 には看板を材料にするレシピがなく、鉄インゴット 1 個を使う不定形のレシピは火打石と打ち金だけなので、ぶつからない。無地に戻すレシピは 0.3.0 からのもの（`safetysigns:clear_sign`）のまま）

## 2. README・doc

- `README.md`（日本語）と `README.en.md`（英語）: ダウンロード、対応する版（Minecraft 1.12.2 + Forge。開発・動作確認は Forge 14.23.5.2860）、操作、図柄の一覧（`doc/textures/preview.png` を使う）、レシピ。
- 両方の README に「ISO（国際標準化機構）とは無関係の非公式 Mod です」と明記する。
- CurseForge・Modrinth に貼る説明文を `doc/store/description.md` に用意する（英語と日本語。同じく非公式であることを明記する）。
- `doc/resourcepack.md`: リソースパックで図柄を追加する方法（定義ファイルの形、テクスチャの置き場所、ID の名前空間、夜間に光る設定のこと）。
- `CHANGELOG.md` に 1.0.0 を書く。

## 3. リリース

- 版を `1.0.0` にする（`build.gradle` の `version` と `SafetySignsMod.VERSION`）。
- `acceptableRemoteVersions` を 1.0 系同士で接続できる範囲（`[1.0,1.1)`）にする。0.x とは接続できない（`CHANGELOG.md` に書く）。
- jar を `build/release/` にコピーしてユーザーに渡す。
- タグ `v1.0.0` は、PR が Merge されたのを確かめてから Claude が付ける。GitHub Release は Actions が作る。
- CurseForge・Modrinth への登録はユーザーが行う（公開前に、同名の Mod がないか・Modrinth の AI 生成コンテンツの申告が要るかを確かめる。MVP の仕様書 12）。
