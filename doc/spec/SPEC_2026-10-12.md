# Safety Signs MVP 仕様書（2026-10-12）

ISO 7010 の安全標識をモチーフにした、装飾用の警告看板を追加する Minecraft Mod。
きっかけは、マルチプレイで IC2 の原子炉を置く場所に、実物と同じ見た目の警告看板を立てたいこと。看板は見た目だけで、ゲーム上の効果はない。

## 1. 全体像

- 追加するのは、形とサイズごとの看板 3 種（MVP）。
- 看板の図柄は、設置後にいつでも GUI で選べる。図柄はアイテムとブロックの NBT に図柄 ID の文字列で持つ。
- 図柄の一覧は定義ファイル（JSON）で持ち、jar に内蔵する。リソースパックから図柄を追加できる。
- 最終的には ISO 7010 の全種（約 330 種）を網羅する。MVP は原子炉まわりで使う 8 種だけ。

## 2. 看板の種類（MVP）

| アイテム | 大きさ | 置き方 |
|---|---|---|
| 壁掛け看板 1×1 | 1 ブロック | 壁に貼る薄い板（額縁くらいの厚さ） |
| 壁掛け看板 2×2 | 2×2 ブロック | 壁に貼る薄い板。複数ブロック方式 |
| ポール付き看板 | 縦 2 ブロック | 床に置く。下段が支柱、上段に 1×1 の看板 |

- サイズ違いは別のアイテム。図柄違いは同じアイテムで NBT だけが違う（スタックしないのは仕様）。
- 向きは 4 方向。置いた人の向きに合わせる。
- 裏面は無地の金属板。

### 2.1 複数ブロック方式（2×2 とポール付き）

- 置くとき、必要なマスがすべて置き換え可能（空気など）でなければ設置に失敗する（アイテムは減らない）。
- 1 マスでも壊れたら全体が消え、アイテムは 1 個だけ落ちる（クリエイティブでは落とさない）。
- 図柄は代表の 1 マスが持つ。どのマスを右クリックしても同じ看板として扱う。

（注: 実装では、正面から見て置いた所が左下（代表のマス）になり、右・上へ広がる。置き換え可能に加えて、高さの範囲・スポーン保護・人とぶつからないことも確かめる。ピストンでは動かない・壊れない（1×1 と同じ）。2×2 は横 2 縦 2 で縦横比が 1×1 と同じなので、GUI のプレビューは 1×1 と同じ正方形。詳しくは `doc/diagrams/multiblock.md` と ADR 0004）

### 2.2 ポールの見た目

- 支柱は 4 ピクセル角（フェンスと同じ細さ）。
- 色は亜鉛メッキ風の `#A7ADB2` を基調にする。
- 2×2 用のポールは MVP にない。後で細く見えたら、太くするか 2 本足にする（`doc/TODO.md`）。

（注: [SPEC_2026-10-12-2.md](SPEC_2026-10-12-2.md) で、縦 3 ブロック・ポールの色 `#DDE0E2`・固定金具 2 か所に変えた。実装では、置いた所の最下段の支柱が代表のマスで、図柄の TileEntity を持つ。床に置く判定は、クリックした面が上面かだけを見る。詳しくは ADR 0005）

## 3. 図柄

### 3.1 MVP の図柄（8 種）

| ID | 種類 | 内容 |
|---|---|---|
| `safetysigns:w001` | 警告 | 一般警告 |
| `safetysigns:w002` | 警告 | 爆発物 |
| `safetysigns:w003` | 警告 | 放射性物質・電離放射線 |
| `safetysigns:w012` | 警告 | 感電注意 |
| `safetysigns:w017` | 警告 | 高温注意 |
| `safetysigns:m010` | 指示 | 防護服着用 |
| `safetysigns:p004` | 禁止 | 通行禁止 |
| `safetysigns:p010` | 禁止 | 触るな |

- 図柄 ID は名前空間付き（`<namespace>:<名前>`）。本体の図柄は `safetysigns:` に ISO のコードを小文字で付ける。
- 図柄を設定していない看板は「無地」（NBT なし）。

### 3.2 定義ファイル

- 置き場所は `assets/<namespace>/safetysigns/signs.json`。読み込みは `IResourceManager.getAllResources` で、有効なすべてのリソースパック（jar 内蔵を含む）の同じパスのファイルを読み、マージする。
- 同じ ID が複数のパックにあれば、優先度の高いパックの定義で上書きする。
- 1 件の項目（形は案。Claude Code が実装に合わせて決めてよい）:

```json
{
  "id": "safetysigns:w003",
  "category": "W",
  "code": "W003",
  "texture": "safetysigns:textures/signs/w003.png",
  "names": { "en_us": "Radioactive material or ionizing radiation", "ja_jp": "放射性物質・電離放射線" },
  "keywords": ["radiation", "nuclear", "放射線", "原子炉"]
}
```

（注: 実装では、ファイルは `{"signs": [ 項目, … ]}` の形。`texture` はブロックのテクスチャの名前 `safetysigns:signs/w003`（`textures/` と `.png` を付けない）。項目の ID の名前空間はファイルの名前空間と同じに限る。詳しくは `doc/resourcepack.md` と ADR 0002）

- `category` は ISO 7010 の 5 分類（`E` 安全状態 / `F` 防火 / `M` 指示 / `P` 禁止 / `W` 警告）。
- 名前は日英の両方を定義ファイルに持つ（検索は表示言語に関係なく日英の両方を対象にするため）。
- 読み込みはクライアントだけ。サーバーは図柄の一覧を知らなくてよく、図柄 ID の文字列を保存・同期するだけ。
- 一覧にない ID（追加パックを入れていない人など）は「?」の図柄で表示する。ID 自体は消さずに保持する。
- サーバーは、クライアントから届いた図柄 ID の形（`<namespace>:<名前>`、長さ 64 文字まで）だけを確かめる。（注: 実装では、CLAUDE.md の約束どおり、看板まで 8 ブロック以内か・スポーン保護の外かも確かめる）

### 3.3 テクスチャ

- 1 図柄 = 32×32 の PNG 1 枚。全サイズで使い回す（2×2 では 1 ブロックあたり 16 ピクセル相当）。
- 黄色の地・黒い枠など、標識の形と枠もテクスチャに含める。
- Claude Code が生成スクリプトで作る（`tools/texgen/`、Python 3 + Pillow）。図形（三角形・円・枠・放射線マーク・稲妻・炎など）を描き、32×32 に出力する。
- 生成した PNG はコミットする（ビルドに Python を持ち込まない）。
- レビュー用に、全図柄を 8 倍に拡大して並べた一覧画像を `doc/textures/preview.png` に出力する。
- 人物入りの図柄（MVP では `m010`）は図形の組み合わせだと不自然になりやすい。生成後にドットを直接打って仕上げてよい。手で仕上げた図柄はスクリプトで上書きしない仕組みにする。
- 色（ISO 3864 の安全色の近似）:

| 用途 | 色 |
|---|---|
| 警告の黄 | `#F9A800` |
| 黒（枠・記号） | `#1A1A1A` |
| 禁止・防火の赤 | `#9B2423` |
| 指示の青 | `#005387` |
| 安全状態の緑 | `#237F52` |
| 白 | `#FFFFFF` |

- 形のきまり: 警告 = 黄の正三角形に黒枠、禁止 = 白地に赤い円と斜線、指示 = 青い円、安全状態・防火 = 緑・赤の四角。
- 正三角形は 31 ピクセル幅で描き、頂点を 1 ピクセルにする。

### 3.4 夜間の描画

- 看板の面だけを明るさ最大で描画する（周りは照らさない。光源ブロックにはしない）。
- クライアント設定 `fullbright`（既定 ON）で切り替えられる。

## 4. 操作

| 操作 | 結果 |
|---|---|
| 看板アイテムで右クリック | 設置。アイテムの図柄をそのまま引き継ぐ |
| 設置済みの看板を右クリック（看板アイテム以外を持っている・素手） | 図柄選択の GUI を開く |
| 看板アイテムを持ってスニーク + 設置済みの看板を右クリック | 設置済みの看板の図柄を、手に持った看板アイテムに写す（種類・サイズは違ってよい） |
| ピックブロック（ホイールクリック） | 図柄入りのアイテムを返す（実質クリエイティブ向け） |
| 看板を壊す | 図柄を保持したアイテムが落ちる |
| 看板アイテム 1 個だけをクラフト枠に入れる | 同じアイテムの無地（NBT なし）になる |

（注: 実装では、スニーク中に看板アイテム以外の物を持って看板を右クリックすると、GUI は開かず、バニラどおりその物を使う（素手なら GUI）。コピーはスタックしたアイテムにまとめて写す。無地に戻すレシピは、もともと NBT のないアイテムでは何も出さない。分岐の図は `doc/diagrams/right-click.md`、決定は ADR 0003）

- 無地の看板を置いても GUI は自動では開かない。
- マルチでは誰でも図柄を変えられる（ロック機能は後回し）。

## 5. GUI

- バニラ風の灰色パネル（背景 `#C6C6C6`、文字 `#404040`）。
- 上にカテゴリのタブ（`W` `P` `M` `E` `F`）。選択中のタブだけ安全色、ほかは灰色。図柄がないタブは押せない表示にする。
  - `W` `#F9A800` / `P` `#9B2423` / `M` `#005387` / `E` `#237F52` / `F` `#9B2423`（文字色で `P` と区別）
- 左に図柄のグリッド（スクロールあり）。マウスを乗せるとコードと名前のツールチップ。
- 右に選択中の図柄の大きなプレビューとコード・名前。2×2 の看板なら、その縦横比で表示する。
- 下に検索欄と「無地に戻す」ボタン。
- **クリックで即反映**（決定ボタンなし）。選ぶたびにサーバーへ送る。
- **検索**: 入力のたびに絞り込む。全カテゴリ横断（検索中はタブの選択を外す）。対象はコード（大文字小文字を区別しない）・日本語名・英語名・`keywords`。（注: 実装では図柄 ID も対象。空白で区切った語はすべてを含むものに絞る。名前・キーワードも大文字小文字を区別しない）
- 開いている間に看板が壊れたら、GUI を閉じる。

## 6. レシピ

- 素材はバニラが基本。鉱石辞書で他 Mod の素材も受け付ける。

| 作るもの | 材料 | 個数 |
|---|---|---|
| 壁掛け看板 1×1 | 鉄（`ingotIron` または `plateIron`）3 + 黄色の染料（`dyeYellow`）1 + 黒の染料（`dyeBlack`）1 | 6 |
| 壁掛け看板 2×2 | 壁掛け看板 1×1 を 4 枚（2×2 に並べる） | 1 |
| ポール付き看板 | 壁掛け看板 1×1 + その下に鉄格子 | 1 |
| 無地に戻す | 看板アイテム 1 個だけ | 1 |

- 材料にした看板の図柄は引き継がない（完成品は無地）。
- 形と並べ方は Claude Code が決めてよい。決めたら README と `doc/` に書く。

## 7. 設定

- `@Config`（`config/safetysigns.cfg`）。
- MVP の項目はクライアントの `fullbright`（既定 true）だけ。

## 8. テスト

純粋な計算だけを `common/`（Minecraft のクラスを持ち込まない）に置き、単体テストを書く。

- 複数ブロックの設置判定（必要なマスの計算、置けるかどうか）
- 検索の絞り込み（コード・日英の名前・キーワード、大文字小文字）
- 定義ファイルのマージ（同じ ID の上書き）と、一覧にない ID の扱い
- 図柄 ID の形の確認

描画・GUI の見た目・設置の手触りは Claude が確かめられないので、jar をユーザーのホスト側の Minecraft と testserver（マルチ）で確かめてもらう。

## 9. 作業の順番（MVP）

1. 雛形（Gradle・`@Mod`・CI）と、図柄を固定した壁掛け看板 1×1
2. 定義ファイル・NBT・GUI（検索・即反映）
3. コピー（スニーク右クリック・ピックブロック）、単体クラフトで無地に戻す、壊したときに図柄を保持
4. 壁掛け看板 2×2（複数ブロック方式）
5. ポール付き看板
6. 夜間の描画と設定
7. テクスチャ生成スクリプトと 8 種の図柄
8. レシピと鉱石辞書、README、リリース

1 つ終わるごとに PR を作り、ユーザーが手元で確かめてから次に進む。

## 10. README・doc

- `README.md`（日本語）と `README.en.md`（英語）。ダウンロード・対応する版・操作・図柄の一覧・レシピ。
- 両方の README と配布サイトの説明文に「ISO（国際標準化機構）とは無関係の非公式 Mod です」と明記する。
