# Safety Signs 仕様書（2026-10-25・その 3）: 図柄を選ぶ画面の見直しと、最近使った図柄

図柄を選ぶ画面（`GuiSignPicker`）に閉じるボタンを付け、ボタンの並び・文字・ツールチップを見直す。最近使った図柄のタブを足す。
ここに書いていないことは、それまでの仕様書と現行の実装のまま。3 つの版（1.12.2・1.20.1・1.21.1）で同じにする。

同じ日に 3 つ目の仕様書なので、ファイル名の日付のあとに `-3` を付けた。

## 1. 配置

```
┌────────────────────────────────────────────┐
│ 図柄を選ぶ                            [×]  │
│ [最近][W][P][M][E][F][GHS][その他]         │
│ ┌──────────────────┐▕   ┌────────┐       │
│ │ 図柄 6×6         │▕   │プレビュー│       │
│ │ 選択中は黄枠     │▕   └────────┘       │
│ │                  │▕     コード         │
│ │                  │▕     名前           │
│ └──────────────────┘                      │
│ [検索…                ]  [ 無地に戻す ]    │
│ [形: 標識 ] [裏側: 図柄] [蓄光: あり]      │
└────────────────────────────────────────────┘
```

- パネルの大きさ（256×224）は変えない。
- 夜間に光るかのボタンをプレビューの下から外し、切り抜き・裏面と一緒に一番下の段へ横に 3 つ並べる（幅を 3 等分）。空いたプレビューの下は、コードと名前の欄にする（あわせて 6 行まで）。

## 2. 閉じるボタン

- パネルの右上、題と同じ行に「×」のボタン（12×12）を置く。押すと画面を閉じる（Esc と同じ）。
- 普段は `#8B8B8B` の地に白 `#FFFFFF` の「×」。マウスを乗せると地を `#9B2423` にする。
- ツールチップ: 「閉じる（Esc）」/ 「Close (Esc)」。
- E（インベントリのキー）で閉じる機能は足さない（検索欄に焦点があり、`E001` のようなコードを打てなくなるため）。

## 3. 設定のボタン

ON/OFF の表示をやめ、今の状態を言葉で書く。

| ボタン | 日本語 | 英語 |
|---|---|---|
| 切り抜き | 形: 標識 / 形: 四角 | Shape: Sign / Shape: Square |
| 裏面 | 裏側: 図柄 / 裏側: 金属 | Back: Pattern / Back: Silver |
| 夜間に光る | 蓄光: あり / 蓄光: なし | Glow: On / Glow: Off |

- 色は「蓄光」の値にだけ付ける: あり `#55FF55`、なし `#AAAAAA`。形と裏側は普通のボタンの文字色。
- 押したときの動き（そのたびにサーバーへ送る・無地のあいだ切り抜きは押せない）は今のまま。

ツールチップ:

| ボタン | 日本語 | 英語 |
|---|---|---|
| 形 | 標識の形に合わせて板を切り抜きます。四角にすると、明るい金属の四角い板の上に標識を描きます | Cuts the plate to the shape of the sign. Square draws the sign on a light metal square plate |
| 形（無地のとき・押せない） | 無地の看板は四角だけです | Blank signs are always square |
| 裏側 | 看板の裏側に、表と同じ図柄を描くか、金属にするかを選びます | Shows the same pattern on the back, or bare metal |
| 蓄光 | 暗い所でも図柄が明るく見えます | Keeps the pattern bright in the dark |

（英語の文は実装のときに整えてよい）

（注: 実装では、四角い板の下地は白ではなく明るい金属の色 `#E4E6E8`（[その 3](SPEC_2026-10-12-3.md)）なので、形のツールチップは「明るい金属の四角い板」にした。文字の長いタブの左右の余白を 10 から 8 ピクセルにした（英語で「Recent」のタブを足すとパネルの幅を超えるため）。言語のキーは、閉じる `gui.safetysigns.close`、「最近」`gui.safetysigns.tab.recent`・`.tooltip`、形の値 `gui.safetysigns.cutout.sign`・`.square`（`.on`・`.off` は消した）、ツールチップは各ボタンのキーの後ろに `.tooltip`（形の無地のときは `.tooltip_blank`））

## 4. そのほかの見た目と操作

- タブにマウスを乗せたら、地を少し明るくする（`#8B8B8B` → `#A0A0A0`）。押せないタブと選択中のタブは変えない。
- 選んでいる図柄のマスを、白い背景に加えて黄 `#F9A800` の枠（1 ピクセル）で囲む。
- 検索欄を右クリックしたら、文字を消す（バニラのクリエイティブの検索と同じ）。消すとタブの表示に戻る。
- 画面の題「図柄を選ぶ」と「無地に戻す」は今のまま。

## 5. 最近使った図柄

### 5.1 タブ

- タブの列の左端（W の前）に「最近」/「Recent」のタブを足す。ツールチップは「最近使った図柄」/「Recently used」。
- 選択中は濃い灰 `#404040` の地に白 `#FFFFFF` の文字。
- 新しいものから並べる（左上が一番新しい）。最大 18 個（3 行）。
- 履歴が空、または履歴の図柄がすべて一覧にないときは、押せない表示（ほかの図柄のないタブと同じ）。
- 開いたときのタブは今のまま（今の図柄のカテゴリ）。「最近」から開くことはない。
- 検索中は、ほかのタブと同じく選択を外す。検索欄を空にしたときに戻るタブも今のまま（今の図柄のカテゴリ）。

### 5.2 何を記録するか

- GUI で図柄のマスをクリックしたときだけ記録する。「無地に戻す」・設定の切り替え・アイテムへの写し・設置では記録しない。
- 先頭に足し、同じ ID がすでにあれば先頭へ移す。19 個目から後ろは捨てる。
- 今選んでいる図柄をもう一度クリックしたとき（サーバーへ送らないとき）は、記録しない。
- 一覧にない ID（パックを外したなど）も 18 個の中に数えて残す。「最近」のタブには出さない（パックを戻すとまた出る）。新しい図柄を使えば、古い順に押し出される。

### 5.3 保存

- クライアントだけが、設定のフォルダの `safetysigns_recent.json` に保存する（普通は `.minecraft/config/`。1.12.2 は `Loader.instance().getConfigDir()`、1.20.1・1.21.1 は `FMLPaths.CONFIGDIR`）。ワールド・サーバーをまたいで同じ履歴。サーバーは作らない・読まない。

```json
{
  "version": 1,
  "recent": [
    "safetysigns:w001",
    "safetysigns:p002"
  ]
}
```

- 文字コードは UTF-8。
- 読むのは、起動してから初めて GUI を開いたときに 1 回だけ。以後はメモリの履歴を使う。
- 書くのは、記録するたび（クリックのたび）。いったん `safetysigns_recent.json.tmp` に書いてから置き換え、書いている途中で落ちても壊れないようにする。
- 読むとき:
  - ファイルがない → 空として始める。
  - 読めない・JSON が壊れている → 空として始め、ログに警告を 1 行出す。次に記録したときに正しい形で書き直す。
  - 知らないキーは無視する。
  - 形の正しくない ID（`<namespace>:<名前>`、64 文字まで。`SignIds` で確かめる）と、19 個目から後ろは読み飛ばす。
- 書けないとき（権限がないなど）は、ログに警告を 1 行出すだけでゲームは止めない。履歴はその起動中だけ残る。
- ファイルは多くても 18 個（約 1.2 KB）で、増え続けない。

### 5.4 作り

- 履歴の計算（先頭に足す・重複を移す・18 個で切る・JSON から読む / 書く）は Minecraft に依存しないので `common/` に置き、単体テストを書く（JSON は `common/` で使っている Gson）。
- ファイルの読み書きと設定のフォルダの場所は、各版のクライアント側のコード。
- `doc/diagrams/gui-sign-picker.md` の図に「最近」のタブを足す。履歴の読み書きは `doc/architecture.md` に書く。

## 7.1 看板アイテムのツールチップ

（ユーザーの指示で足した）看板アイテムのツールチップの設定の行を、3 章のボタンの言い方に揃える。既定と違う設定だけ 1 行ずつ出すのは今のまま。キー（`tooltip.safetysigns.no_cutout` など）は変えず、値だけ変える。設定の行は、図柄の名前と区別するため灰色 `#AAAAAA`（バニラの補足と同じ）にする。ストアの説明文の設定の名前も、形・裏側・蓄光に揃える。

| 出るとき | 今 | 変えたあと |
|---|---|---|
| 切り抜き OFF | 切り抜きなし / Not cut out | 形: 四角 / Shape: Square |
| 裏面が図柄 | 両面 / Double-sided | 裏側: 図柄 / Back: Pattern |
| 夜間に光らない | 光らない / Does not glow | 蓄光: なし / Glow: Off |
