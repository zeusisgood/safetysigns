# Safety Signs 仕様書（2026-10-25）: アイテムのアイコンを描き分ける・公開前の仕上げ

CurseForge に公開する前の仕上げ。今は 3 種のアイテム（壁掛け 1×1・壁掛け 2×2・ポール付き）がどれも無地の板 `blocks/sign_blank` を貼っているだけで、インベントリでは名前とツールチップでしか区別できない（`doc/TODO.md`）。アイテム専用のアイコンを形で描き分け、あわせて CurseForge のアイコン・`mcmod.info`・説明文を整える。
ここに書いていないことは、それまでの仕様書と現行の実装のまま。

公開先は **CurseForge だけ**（Modrinth は今回は出さない）。

## 1. アイテムのアイコン

### 1.1 描き方

- 3 種のアイテムに専用のテクスチャを作る: `textures/items/wall_sign_1x1.png`・`wall_sign_2x2.png`・`pole_sign.png`。
- 解像度は **32×32**（固定。生成スクリプトの `--size` には従わない）。ドット絵として描き、アンチエイリアス・中間色・半透明は使わない（図柄と同じ。背景は透明）。
- アイテムのモデル（`models/item/*.json`）は `item/generated` のまま、`layer0` を上のテクスチャに替える。
- 板には 3 種とも**警告の三角**（黄の地に黒の縁。記号は入れない）を描く。
- 描き分けるのは**無地のアイテム**（図柄を持たないもの）のアイコン。図柄を NBT で持つアイテム（看板を壊して拾ったもの・見た目を写したもの）は、今までどおり図柄のテクスチャでアイコンを出す（`SignItemModel`。ADR 0006）。図柄を持つアイテムは 3 種の見分けがつかないままになるので、`doc/TODO.md` に書く。

### 1.2 形と色

| アイテム | 形（目安） |
|---|---|
| 壁掛け 1×1 | 中央に 20×20 ほどの板。板に警告の三角 |
| 壁掛け 2×2 | 枠いっぱい（30×30 ほど）の板。板の縦横の真ん中に、4 枚分を示す 1 ピクセルの分割線。その上に大きい警告の三角 |
| ポール付き | 上に 18×18 ほどの板と警告の三角、その下に 4 ピクセル幅の支柱を下端まで |

| 部分 | 色 |
|---|---|
| 板 | `#E4E6E8`（看板の板と同じ） |
| 板の縁・2×2 の分割線 | `#A7ADB2` |
| 三角の地 | `#F9A800`（警告の黄） |
| 三角の縁 | `#1A1A1A`（1×1・ポール付きは 1 ピクセル、2×2 は 2 ピクセルを目安） |
| 支柱 | `#DDE0E2`、明るい所 `#F0F2F3`、暗い所 `#BABFC3`（ブロックの支柱と同じ） |

- 大きさ・縁の太さは目安。32×32 で三角が潰れない・3 種が一目で区別できることを優先して、実装で決めてよい。
- 色は上の表の色だけを使う（スクリプトで確かめる）。

### 1.3 生成スクリプト

- `tools/texgen/generate.py` が、図柄と同じ実行でアイテムのアイコン 3 枚も出す。
- アイコンを並べた一覧画像 `doc/textures/items.png` を出す（図柄の一覧画像 `preview.png` と同じマスの大きさ・背景。32×32 は 8 倍）。`CLAUDE.md` の文書の表と `doc/development.md` にこの画像を足す。

## 2. CurseForge のアイコン

- 壁掛け 1×1 のアイテムのアイコンを、最近傍で 16 倍に拡大した **512×512** の画像にする。透明な所は暗い灰色 `#2B2F33` で塗る（CurseForge の白・黒どちらの背景でも見えるように）。
- 生成スクリプトが `doc/store/icon.png` に出し、コミットする。jar には入れない。

## 3. `mcmod.info`

| 項目 | 内容 |
|---|---|
| `url` | `https://github.com/zeusisgood/safetysigns`（CurseForge のページができたら、そちらに替える。別の PR） |

| `credits` | `Pictograms drawn for this mod with ISO 7010, the GHS and ISO 21482 as references.` |

## 4. ストアの説明文

- `doc/store/description.md` の冒頭の表に、アイコン（`doc/store/icon.png`）とスクリーンショットの欄を足す。
- スクリーンショットはユーザーが撮る（Claude には撮れない）。撮ってほしい場面を説明文の文書に並べる: 壁掛け 1×1 を並べた所、壁掛け 2×2、ポール付き、図柄を選ぶ画面、夜に光る看板、切り抜き OFF・裏面の違い。
- 公開先は CurseForge だけと書き添える（説明文そのものは Markdown のまま、Modrinth にも貼れる形のまま）。

## 5. 版

- 図柄 ID・通信内容・保存データは変えないので、パッチで **`1.0.5`** にする（1.0.x 同士で接続できる）。
- `CHANGELOG.md` に、アイテムのアイコンを 3 種で描き分けたこと、Forge の Mod 一覧にロゴを出すことを書く。
- `doc/TODO.md` の「アイテムのアイコンが 1×1 と同じ」を、「図柄を持つアイテムは図柄のアイコンになるので、3 種の見分けがつかない（名前とツールチップだけ）」に書き換える。
