# 手で仕上げた図柄

ここに `<名前>.png`（32×32）を置くと、`generate.py` はその図柄を生成せず、このファイルをそのまま
`src/main/resources/assets/safetysigns/textures/signs/<名前>.png` にコピーする。スクリプトを流し直しても、手の仕上げは消えない。

- 生成した図柄を仕上げるときは、`textures/signs/<名前>.png` をここにコピーしてから、ドットを打つ。
- `generate.py` の `SIGNS` にない名前でも置ける（手で描いただけの図柄）。一覧画像の最後に並ぶ。
- 使ってよい色は生成と同じ（`parts.py` の色と透明だけ）。外れた色・半透明があると警告を出す（出力はする）。大きさが 32×32 でなければ止まる。
- 生成に戻すときは、ここのファイルを消して `generate.py` を流し直す。

詳しくは `doc/development.md`。
